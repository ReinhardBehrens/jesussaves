# Platform marks

These marks identify the platforms targeted by the community downloads.

- `ubuntu.svg`: Canonical's unmodified orange 2022 Circle of Friends asset, from [assets.ubuntu.com](https://assets.ubuntu.com/v1/ce518a18-CoF-2022_solid+O.svg). [Ubuntu brand resources](https://design.ubuntu.com/resources).
- `windows.svg`: a geometric rendering of the blue, equal four-pane Windows 11 symbol, following the [Microsoft Windows brand reference](https://cdn-dynmedia-1.microsoft.com/is/content/microsoftcorp/microsoft/mscle/documents/presentations/Windows_trademark_guidelines_2025.pdf). It is not the four-colour Microsoft corporate logo or the older perspective Windows flag.
- `download-ubuntu.svg` and `download-windows.svg`: project download buttons incorporating those marks. The Ubuntu symbol retains its original geometry and colour.

Ubuntu and Windows are trademarks of their respective owners. Their inclusion identifies compatibility and does not imply endorsement. The platform marks are not presented as original GPL project artwork.
