# Asset provenance

The background was made with OpenAI's **built-in image generation tool**, then copied into this project. No API key is required to build or run the screensaver.

- `assets/heaven-source.png`: original generated source, 1672 × 941.
- `assets/heaven-4k.png`: 3840 × 2160 background exported through the application's bilinear GPU background pass. This is an upscale, not native 4K generated detail.
- `docs/screenshot-4k.png`: a real 4K rendered application frame, including runtime gold lettering and flames.
- `assets/text-sdf.bin`: little-endian float32 signed-distance field generated from DejaVu Sans Bold at 1536 × 256. Regenerate with `python3 scripts/generate_text.py`; requires Pillow and `fonts-dejavu-core`. Font notice: `licenses/DejaVu.txt`.
- `assets/turbulence.bin`: seamless five-scale random float field generated by `scripts/generate_turbulence.py`; the generator uses a fixed seed.
- `build/background.bgra`: generated during compilation by encoding the checked-in PNG as BGRA; it is not stored in Git.

## Original background prompt

```text
Use case: stylized-concept. Asset type: native 4K 3840x2160 landscape background texture for a Christian 3D text and flame screensaver. Generate exactly 3840 by 2160 pixels. Subject: an awe-inspiring serene vision of heaven represented by realistic voluminous pearly clouds opening toward soft radiant golden-white sunlight, delicate shafts of light, subtle blue-gray atmosphere. Cinematic photorealistic cloud detail, sophisticated and tranquil, not cartoon. Composition: luminous cloud opening in the top third, clouds framing the upper corners; progressively darker charcoal clouds through the middle, fading very smoothly to completely pure black over the entire lower 40 percent. Upper center has restrained brightness so reflective gold text will remain visible when composited later. Lower area must be pure black for animated fire overlay. No text, no letters, no people, no figures, no buildings, no fire, no logos, no watermark. Beautiful fine 4K detail, widescreen 16:9.
```

## Follow-up image-tool prompt

```text
Upscale this exact background to 3840x2160 pixels, 4K UHD landscape 16:9. Preserve the cloud composition, golden heaven light and smooth fade to pure black at the bottom. Increase fine photorealistic cloud detail. No text, no additional objects. Output exactly 3840 x 2160, not a smaller preview resolution.
```

The tool still returned a smaller image. The application therefore performs the documented 4K export. The original composition is retained. CPU and GPU text are calculated at final render resolution; their sharpness does not depend on the background's source resolution.

## 3D README icon

`docs/logo-3d.png` is the final built-in image-generation edit, **1254 × 1254 pixels**, with an alpha-transparent background outside the gold frame. It is displayed at 400 pixels wide in the README. The original landscape outputs were 1672 × 941 pixels despite requests for 3840 × 2160. This file is therefore not labelled as a native 4K asset. The previous vector icon remains at `docs/logo.svg`.

Generation used the built-in tool, not the CLI/API fallback. Final prompt sequence:

Physically based 3D product rendering, ray-traced gold reflections, beautifully resolved bevels, subtle brushed-metal microtexture, dramatic studio lighting, crisp silhouette that stays readable at 180px, rich contrast, tasteful and reverent. ## Transparent icon edit

The built-in image tool isolated the icon from the supplied landscape image. The output was copied unchanged into `docs/logo-3d.png`; transparency was verified from its RGBA alpha channel.

```text
Edit this exact icon asset: remove ONLY the black/navy background OUTSIDE the rounded gold outer frame. Keep the entire gold frame and everything inside it unchanged: cross, clouds, light and flames. Output just the isolated rounded-square icon on a truly transparent alpha background, with clean antialiased edges and no rectangular black background, no checkerboard drawn into pixels, no external shadow. Crop the canvas tightly to the icon with a very small transparent margin. Square PNG asset. Preserve original design and high detail; do not redesign.
```
